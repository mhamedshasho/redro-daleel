دليل الإعداد

كيف تدخل إلى لوحة الإدارة؟

لوحة الإدارة ليست حساباً عاماً. يجب أولاً نشر المشروع وربط خدمات Cloudflare، ثم إنشاء مفتاح سري خاص بك.

1. أنشئ مشروع Cloudflare Pages

  1. اربط مستودع mhamedshasho/redro-daleel بحساب Cloudflare Pages من GitHub.
  2. اجعل مجلد البناء public، واترك إعدادات Functions مفعلة من مجلد functions.
  3. لا تستخدم GitHub Pages؛ هذا المشروع يحتاج Pages Functions وD1 وR2.

2. اربط قاعدة D1 وتخزين R2

  1. أنشئ D1 باسم redro-daleel.
  2. أنشئ R2 bucket واختر اسماً له.
  3. حدّث wrangler.toml: استبدل قيمة REPLACE_WITH_CLOUDFLARE_D1_DATABASE_ID بمعرّف D1، وREPLACE_WITH_R2_BUCKET_NAME باسم الحاوية.
  4. طبّق كل ملفات migrations/ على D1 بالترتيب، من 0001 إلى 0005.
  5. في إعدادات Pages، أضف binding باسم DB من نوع D1 وbinding باسم IMAGES من نوع R2.

3. أضف متغيرات وأسرار Pages

أضف الأسرار التالية في إعدادات المشروع، ضمن Production وكذلك Preview إذا أردت اختبار المعاينة:

  • ADMIN_API_KEY: مفتاح عشوائي طويل تحفظه أنت في مدير كلمات المرور. هذا هو المفتاح الذي تدخله في صفحة الإدارة.
  • GEMINI_API_KEY وGEMINI_MODEL: لمراجعة الطلبات بالذكاء الاصطناعي.
  • TURNSTILE_SECRET: مفتاح Turnstile السري.

لا تضع هذه المفاتيح داخل ملفات JavaScript أو HTML ولا ترسلها في المحادثات.

4. تحقق ثم ادخل

  1. انتظر نجاح نشر Pages.
  2. افتح /api/health وتحقق من ظهور قاعدة البيانات ومفتاح الإدارة بحالة جاهزة. يمكن أن تبقى خدمات Gemini أو Turnstile غير مضبوطة أثناء اختبار لوحة الإدارة فقط.
  3. افتح /admin.html، وأدخل قيمة ADMIN_API_KEY نفسها.

مهم: لا يمكنني إنشاء موارد داخل حساب Cloudflare أو ضبط أسرارك من المستودع وحده. هذه الخطوات تحتاج صلاحية حساب Cloudflare الخاص بك. لا تنشر مفاتيحك في GitHub.
